# TaskYa

Marketplace de servicios profesionales para Ecuador. Conecta clientes con profesionales independientes y empresas: publica proyectos, compara propuestas, contrata y paga con protección.

Landing page del producto — diseño con animaciones de scroll, mockups de la app y secciones de cómo funciona, seguridad, categorías, precios, testimonios y FAQ.

## Modelo

- **Clientes:** gratis.
- **Profesionales:** comisión del 15% sobre cada trabajo completado.

## Desarrollo

Es un sitio estático. Abre `index.html` en el navegador o sírvelo con cualquier servidor estático.
